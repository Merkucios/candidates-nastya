# candidates-nastya

# Техническое задание: Сайт тестирования вожатых (финальная версия)

## 1. Общее описание проекта

Веб-сайт для обучения и аттестации вожатых. Состоит из двух частей:
- **Публичная часть** — для вожатых (просмотр материалов + прохождение теста)
- **Административная часть** — для управления тестом (конструктор вопросов) и просмотра результатов (защищена мастер-паролем)

---

## 2. Технологический стек

- **Frontend:** React
- **База данных:** Neon
- **Хостинг:** Vercel
- **Хранение видео:** Google Drive / Яндекс.Диск (embed по ссылке)

---

## 3. Структура сайта

### 3.1. Публичная часть (для вожатых)

**Страница 1 — Форма регистрации**
- ФИО, номер телефона, email
- Кнопка «Начать обучение»

**Страница 2 — Обучающие материалы**
- Видео 1, Видео 2 (embed)
- Презентация (embed)
- Кнопка «Перейти к тестированию»

**Страница 3 — Тестирование**
Вопросы подгружаются динамически из базы данных, поддерживаются 3 типа:

1. **Один правильный ответ** (radio) — засчитывается автоматически, влияет на итоговый балл
2. **Несколько правильных ответов** (checkbox) — засчитывается автоматически, влияет на итоговый балл
3. **Текстовый ответ / открытый вопрос** (textarea) — **НЕ проверяется и НЕ влияет на балл**. Это вопрос "для размышления/обратной связи" — ответ просто сохраняется в базе, чтобы админ мог его прочитать при желании

Кандидат может проходить тест неограниченное количество раз (без ограничений/проверки уникальности).

**Страница 4 — Финальный экран**
- Просто: «Спасибо за прохождение теста!»
- **Кандидат НЕ видит свой балл, результат, статус сдал/не сдал** — вообще никакой информации об итоге

---

### 3.2. Административная часть

**Страница входа**
- Одно поле: «Мастер-пароль»

**Дашборд администратора** — два раздела:

#### Раздел А: Результаты тестирования
- Таблица всех прохождений: ФИО, телефон, email, дата, итоговый балл (виден только админу)
- Детальный просмотр — все ответы конкретного вожатого на все вопросы, включая текстовые ответы (админ читает их вручную, это не влияет на балл, просто для ознакомления)
- (Опционально) экспорт в Excel/CSV

#### Раздел Б: Конструктор теста
1. Список всех вопросов с порядком отображения
2. Добавление нового вопроса:
   - Текст вопроса
   - Тип: (a) один правильный ответ / (b) несколько правильных ответов / (c) текстовый/открытый вопрос
   - Для (a) и (b) — динамические поля вариантов ответа + отметка правильного варианта(ов)
   - Для (c) — просто текст вопроса, без вариантов и без эталона (ответ не проверяется)
3. Редактирование существующего вопроса
4. Удаление вопроса
5. Изменение порядка вопросов (числовое поле order_index)
6. Управление ссылками на видео/презентацию (без участия разработчика)

## 4. Структура базы данных (Supabase)

|---|---|

| phone | text |
| email | text |
| created_at | timestamp |
| score | integer (видит только админ) |
| total_scored_questions | integer (кол-во вопросов, влияющих на балл) |

### `questions`
| Поле | Тип |
|---|---|
| id | uuid, PK |
| question_text | text |
| type | text (single / multiple / text) |
| order_index | integer |
| created_at | timestamp |

### `question_options`
| Поле | Тип |
|---|---|
| id | uuid, PK |
| question_id | uuid, FK |
| option_text | text |
| is_correct | boolean |
| order_index | integer |

### `answers`
| Поле | Тип |
|---|---|
| id | uuid, PK |
| candidate_id | uuid, FK |

| Поле | Тип |
|---|---|
| id | uuid, PK |
| video_1_url | text |
| video_2_url | text |

| updated_at | timestamp |

---

## 5. Логика подсчёта результатов

- **Single/Multiple choice** — сравнение с `is_correct` вариантами → влияет на общий балл
- **Text (открытый вопрос)** — НЕ участвует в подсчёте балла, просто сохраняется как текст для прочтения администратором
- Итоговый балл рассчитывается только по вопросам типа single/multiple и виден **только в админке**

---

## 6. Требования к дизайну

- Простой, лаконичный, минималистичный UI
- Адаптивность под мобильные устройства
- Единый стиль (Tailwind + shadcn/ui)

---

## 7. MVP-приоритеты (порядок разработки)

1. Форма регистрации вожатого → сохранение в БД
2. Админ-панель: конструктор вопросов (CRUD)
3. Страница с обучающими материалами (динамические ссылки из settings)
4. Механизм прохождения теста (подгрузка вопросов из БД, без ограничения попыток)
5. Подсчёт балла (только по single/multiple) + сохранение всех ответов, включая текстовые
6. Финальный экран без отображения результата
7. Админ-панель: просмотр результатов + детальный просмотр ответов (включая текстовые)
8. (Опционально) экспорт в Excel
